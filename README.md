# Product Starter

A starter kit for building a real product with an AI coding agent, from your first idea to a
release that people use.

Fork it or click **Use this template**, open it with your agent, and work through four stages:

1. **Idea**: decide whether it's worth building.
2. **Plan**: write a short brief and a list of small tasks.
3. **Build**: one task at a time, each on a branch with a pull request and a review.
4. **Done**: it works end to end, it's tested, and someone else can use it without your help.

> Work in progress. The guide, agent instructions, skills and an example product are still being
> added. See [CHANGELOG.md](CHANGELOG.md) for what each version contains.
